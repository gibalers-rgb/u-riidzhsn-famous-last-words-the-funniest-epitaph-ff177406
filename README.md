A program that writes one funny tombstone epitaph — a single line of famous last words — to `/output/entry.txt`. It keeps three hand-written candidates, scores each against the judge's own rubric (on-subject, real laugh, clean twist, carved-in-stone voice, memorability), and writes the winner. The winning line:

> I can see the light. It's just the fridge — someone left it open again.

(The dying cliché "I can see the light" collapses into a fridge light left open: a real laugh, a clean twist, and a line anyone can repeat to a friend.)

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (71 characters, one line) and verifies it against the gate (1–150 characters, not only whitespace, single line) before exiting.
